## Implementation and safety boundaries
- `src/kernel/apic-irq0.[ch]`: narrow injected hardware IO backend handles IOAPIC IOREGSEL/IOWIN reads and writes and LAPIC SVR/EOI. Read-only preflight rejects unsupported MADT single-LAPIC ID, QEMU-derived IOAPIC pin capacity, unsupported ISA timer ISO polarity/trigger, nonzero local TPR, unmasked LAPIC LINT0 ExtINT, any unmasked unrelated IOAPIC pin, or invalid IRQ0 GSI. No unrelated pin is altered. Stage IOAPIC IRQ0 high destination and masked low `0x10030`, confirm both readbacks, enable LAPIC software spurious vector `0xff`, then configure PIT channel 0 mode2 reload `11932`, then unmask *only* the IRQ0 redirection low to vector `0x30` and verify. A failed post-mutation readback is **fatal with IF=0**, not falsely available. Existing 8259 PIC remains fully masked. IOAPIC selector-latch reads/writes restore the previous selector.
- `src/kernel/x86-irq0.S`: external interrupt gate `0x30` saves **all** 15 GPRs including RBX, uses saved R12 for dynamic 16-byte stack alignment, calls bounded C handler and restores original RSP and registers before `iretq`. Spurious vector `0xff` returns via IRETQ without EOI. Interrupt gate clears IF in handler. No vector/error frame words injected.
- `src/kernel/x86-idt.[ch]`: retain all exception gates, IST1 double fault and absent legacy PIC IRQ gates; install exactly two APIC interrupt gates while IF=0. Hosted IDT tests link benign symbols, not privileged interrupt instructions.
- `src/kernel/main.c`: retain all M9-3D5 MADT, CPUID/MSR, private UC/NX MMIO, known HHDM alias, LAPIC ID and IOAPIC ID/version/GSI safety checks. Only after full hardware preflight install both gates, stage/mask/read-back hardware, program PIT0, unmask IRQ0 and `STI`. The ISR calls `kernel_timer_boot_tick()` then LAPIC EOI, with no heap, serial, locks, scheduling, or blocking. F12 uses independent PIT channel2; PS/2 keyboard and COM1 remain polled. If preflight cannot prove a supported platform, normal diagnostic/editor boot continues with IF=0. A partially programmed or unmask-readback-failed route halts rather than leak untracked interrupts.
- `Makefile`, `tests/apic-irq0-test.c`, `tests/x86-idt-test.c`, `scripts/test-irq0-timing.py`, `scripts/test-irq0-negative.py`, `scripts/qemu.py`: fake MMIO hosted tests reject invalid/unmasked topology and unsupported overrides, ensure only IRQ0 pin is unmasked, readbacks and EOI; real QEMU positive 100/200 tick markers measured against independent host wall clock at 128/256/512MiB. A separate disposable test image deliberately skips routing and proves the timer API stays unavailable with normal boot. Normal QEMU test marker defaults to BOOT_OK; the new optional wait-marker is only used by the timing variant.
