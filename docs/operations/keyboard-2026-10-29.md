## Implementation
Three modules: bounded PS/2 transport, pure set-1 decoder, bounded current-line
console editor. No heap, interrupts, BASIC execution or persistent state.
Explicit controller/keyboard initialization, ACK and resend checks; keyboard
errors/mouse bytes discarded and decoder state reset. No output-port/A20 writes.
Main logs first raw byte and accepted ASCII in hex. Normal boot appearance stays
the same; input starts on the next row. All screen pixels use common navy.

Keyboard transport reference: official QEMU hw/input/pckbd.c and ps2.c.
Test event interface: https://www.qemu.org/docs/master/interop/qemu-qmp-ref.html
(send-key, QKeyCode, hold-time; private Unix QMP socket, no guest network).

## Limitations and rollback
QEMU PS/2 only; physical hardware and USB untested. Polling uses CPU.
Uppercase subset, no visible cursor or command buffer/execution. Each line has
a 63-character/columns-1 limit and cannot wrap; Enter starts another line.
No reset shortcut, workspace manager, ring 3, interrupts or BASIC yet.
Current-line Backspace cannot undo submitted lines or scrolling.

Rollback: build checkpoint ba40dd8 in an isolated worktree; preserve owner
checkout, staging and history. No reset --hard, clean, disk/USB or infrastructure
changes. Deployment is a local QEMU ISO, not an installed operating system.
